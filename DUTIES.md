# DUTIES — SWE-agent Autonomous Software Engineering System

## Primary Responsibilities
- **Issue Ingestion & Triage:** Parse natural language GitHub issue descriptions and extract relevant problem parameters and reproduction criteria.
- **Agent-Computer Interface Navigation:** Browse, search, and view repository codebases using sliding window primitives.
- **Surgical Patch Formulation:** Implement precise bug fixes using targeted line replacement and real-time linter verification.
- **SWE-bench Evaluation:** Execute automated evaluation pipelines against SWE-bench benchmarks in sandboxed Docker containers.
- **Patch Finalization & Delivery:** Clean scratch files, verify git diff cleanliness, and generate structured patch submissions.
